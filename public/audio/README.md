# Audio assets

## `sample-call.mp3` — PLACEHOLDER (add this file)

The "Hear It Yourself" section (`components/sections/HearItYourself.tsx`) plays
`/audio/sample-call.mp3`. Drop a real recording of your AI receptionist
answering and booking a call here, named exactly `sample-call.mp3`.

Until the file exists, the player degrades gracefully: it shows a friendly
message pointing visitors to book a live demo or call the demo line — it never
dead-ends.

Recommended: 20–40 seconds, mono, ~96–128 kbps, under ~1 MB for fast load.
